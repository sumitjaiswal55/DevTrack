# LearnOS — MERN Career Learning Platform

A clean Striver-inspired starting point for a personal learning/career command center.

## Current MVP
- Dashboard with progress, streak, study time, today's plan, syllabus and opportunities.
- Syllabus, day plan, DSA, projects and opportunities navigation.
- React/Vite frontend.
- Express backend API.
- MERN-ready structure; MongoDB persistence comes next.

## Run
1. `npm install`
2. `npm run install-all`
3. `npm run dev`

Frontend: http://localhost:5173
API: http://localhost:5000/api/health
